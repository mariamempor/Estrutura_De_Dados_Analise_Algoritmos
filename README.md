# Simulador de Suporte Técnico de Informática

Projeto acadêmico em Java para demonstrar uso de estruturas de dados:
- Fila (`Queue`)
- Pilha (`Stack`)
- Lista Ligada (`LinkedList`)
- Árvore Binária de Busca (implementação manual)

## Como compilar
```bash
javac -d out $(find src -name "*.java")
```

## Como executar
```bash
java -cp out Main
```

## Funcionalidades
1. Cadastro de usuários
2. Abertura de chamados
3. Atendimento por prioridade
4. Listagem de fila
5. Histórico de atendimento
6. Busca por ID em árvore
7. Relatórios de volume e tempo médio
